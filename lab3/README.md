### 1. Определение текущего дня недели

Для определения текущего дня недели используется функция `date()`.

```php
$dayOfWeek = (int) date('N');
```

Формат `N` возвращает номер дня недели:

```text
1 - понедельник
2 - вторник
3 - среда
4 - четверг
5 - пятница
6 - суббота
7 - воскресенье
```

### 2. Формирование расписания

Для John Styles рабочими днями являются понедельник, среда и пятница.

```php
if ($dayOfWeek == 1 || $dayOfWeek == 3 || $dayOfWeek == 5) {
    $johnSchedule = "8:00-12:00";
} else {
    $johnSchedule = "Нерабочий день";
}
```

Для Jane Doe рабочими днями являются вторник, четверг и суббота.

```php
if ($dayOfWeek == 2 || $dayOfWeek == 4 || $dayOfWeek == 6) {
    $janeSchedule = "12:00-16:00";
} else {
    $janeSchedule = "Нерабочий день";
}
```

Полученные значения выводятся в HTML таблице.

## 3. Цикл for

Начальные значения переменных:

```php
$a = 0;
$b = 0;
```

На каждой итерации значение `$a` увеличивается на `10`, а `$b` увеличивается на `5`.

```php
$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
    $a += 10;
    $b += 5;

    echo "Шаг $i: a = $a, b = $b\n";
}

echo "End of the loop: a = $a, b = $b";
```

После выполнения цикла:

```text
a = 60
b = 30
```

## 4. Цикл while

Та же задача была выполнена с использованием цикла `while`.

```php
$a = 0;
$b = 0;
$i = 0;

while ($i <= 5) {
    $a += 10;
    $b += 5;

    echo "Шаг $i: a = $a, b = $b\n";

    $i++;
}

echo "End of the loop: a = $a, b = $b";
```

Результат:

```text
a = 60
b = 30
```

## 5. Цикл do-while

Последний вариант реализован с помощью цикла `do-while`.

```php
$a = 0;
$b = 0;
$i = 0;

do {
    $a += 10;
    $b += 5;

    echo "Шаг $i: a = $a, b = $b\n";

    $i++;
} while ($i <= 5);

echo "End of the loop: a = $a, b = $b";
```

Результат:

```text
a = 60
b = 30
```

## Контрольные вопросы

### 1. В чем разница между циклами for, while и do-while

Цикл `for` удобно использовать, когда заранее известно количество повторений.

```php
for ($i = 0; $i <= 5; $i++) {
    // код
}
```

Цикл `while` выполняется до тех пор, пока условие остается истинным.

```php
while ($condition) {
    // код
}
```

Условие проверяется перед выполнением тела цикла.

Цикл `do-while` отличается тем, что условие проверяется после выполнения тела цикла.

```php
do {
    // код
} while ($condition);
```

Поэтому `do-while` выполняется минимум один раз.

### 2. Как работает тернарный оператор ? :

Тернарный оператор используется как сокращенный вариант `if else`.

Общий вид:

```php
$result = $condition ? $value1 : $value2;
```

Пример:

```php
$age = 20;

$status = $age >= 18 ? "Совершеннолетний" : "Несовершеннолетний";
```

Если условие истинно, используется первое значение. Если условие ложно, используется второе.

### 3. Что произойдет, если в do-while условие изначально ложно

Тело цикла все равно выполнится один раз.

```php
$i = 10;

do {
    echo $i;
} while ($i < 5);
```

В данном случае будет выведено:

```text
10
```

После этого условие будет проверено, окажется ложным и выполнение цикла завершится.
